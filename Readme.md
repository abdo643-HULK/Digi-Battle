Digi-Battle an Augmented Reality (AR) prototype developed with the Unity Game-Engine and Vuforia. The project aims to modernize the traditional Digimon trading card game by projecting interactive 3D models onto physical cards using mobile devices. The [PDF](./AR_Documentation_Shehata.pdf) provides details about architectural design, the implementation of the AR tracking system, and the game logic used to create a turn-based battle experience.
